R5 Ubuntu Backup

Personal encrypted backup and recovery.

R5 Ubuntu Backup is a private application used by its owner to back up and restore their own computer files. It uses rclone and restic to store encrypted backups in the owner's Google Drive.

Google Drive access

The application requests only the drive.file permission. This limits access to files created by this application or specific files the owner explicitly makes available to it. It does not request access to every file in Google Drive.

Owner controlled

Backup contents are encrypted locally before upload. Authorization tokens are kept privately on the owner's computer. The owner controls backup retention, recovery and deletion, and can revoke the application's Google access at any time.

This is a personal tool, not a public backup service. These information pages have no sign-in form, analytics, tracking scripts or advertising.
